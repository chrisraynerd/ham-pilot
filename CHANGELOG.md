# Releases

## v0.3.4 - first public firmware release

Ham Pilot startup and G1CEC / Chris Raynerd credit; blank station defaults for
new installations; six-row country-led spots and stable detail views; independent
page durations; Info/calendars; selected major contests on the clock. Uses
OFL-licensed Noto Sans for compact proportional text and includes library licence
credits. Existing station settings and touch calibration survive normal updates.

ADIF/DXCC alert development will be separate from this stable baseline.

Release status: unpublished draft. Includes a Settings touch correction awaiting physical verification; ordinary buttons use stable samples and Save requires a press beginning inside Save.
