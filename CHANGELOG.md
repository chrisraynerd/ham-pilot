# Releases

## v0.3.5 - first public release

Includes the tested Ham Pilot baseline: five HF screens, six-row DX spots,
Info/calendars, selected major contests, independent page durations and blank
station defaults. Settings > Wi-Fi opens reliably; Show/Hide on the device lets
you check and correct the existing password. The row clearly indicates whether
a password is set, and explains how to save. Existing settings and calibration
survive normal updates. Live Wi-Fi, time, PSK, cluster and HamQSL verified on
17 October 2026; the user confirmed the display is fully working.

The earlier v0.3.4 candidate was available through the website; its GitHub
release remains an unpublished draft. ADIF/new-DXCC alerts are not included.
